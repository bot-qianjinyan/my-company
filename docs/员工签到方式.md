# 员工签到方式

> 整理目前市场上主流的员工打卡签到方式，供本平台「签到打卡」功能选型参考。国内企业考勤通常按场景组合多种方式，而不是只用一种。钉钉、企业微信、飞书，以及北森、盖雅、i人事等系统，基本都覆盖下面这些方式。

## 一、手机端

手机端是目前使用最广的一类。

| 方式 | 怎么判断「人到了」 | 适合谁 | 主要短板 |
| --- | --- | --- | --- |
| **GPS + 地理围栏** | 人在设定范围内（圆形或多边形）才能打卡 | 外勤、门店、工地、出差 | 室内不准，虚拟定位可作弊 |
| **Wi-Fi 打卡** | 连上公司指定 Wi-Fi（按 BSSID 白名单） | 固定办公室 | 蹭网、热点伪造 |
| **蓝牙 Beacon** | 手机靠近现场蓝牙盒子，精度大约 1–3 米 | 园区、仓库、医院、多楼层室内 | 要布点和维护 |
| **拍照打卡** | 现场拍照，常带时间、地点水印 | 外勤拜访、巡店 | 可事后补拍，通常只做辅助凭证 |
| **手机人脸** | 前置摄像头活体检测 | 要防代打、又不想上考勤机 | 光线、口罩，以及人脸数据合规 |

常见组合：

- 外勤：**GPS 围栏 + 拍照水印**
- 办公室：**Wi-Fi 白名单**，必要时再加 GPS

## 二、现场硬件

工厂、园区、总部大堂更常见硬件签到。硬件侧的默认选项已经从指纹转向人脸，工卡仍大量用于门禁联动。

| 方式 | 特点 | 适合谁 |
| --- | --- | --- |
| **人脸闸机 / 人脸考勤机** | 身份最强，能防代打；要活体检测 | 门禁和考勤合一、安防要求高 |
| **指纹机** | 传统方案，成本低 | 产线、车间；手指磨损、卫生是问题 |
| **工卡 / IC 卡 / NFC** | 刷卡即出入，和门禁数据打通 | 厂区、写字楼 |
| **二维码** | 入口贴动态码，员工扫码 | 临时点、活动、访客；静态码容易被转发 |
| **考勤机直连** | 中控、海康等设备把记录回传系统 | 已有硬件、不想全换手机打卡 |

## 三、按场景选型

| 场景 | 建议 |
| --- | --- |
| 固定办公室 | Wi-Fi 为主，出入口可加门禁或人脸 |
| 工厂 / 园区 | 人脸或工卡 + 门禁，室内再加蓝牙 |
| 外勤 / 销售 / 配送 | GPS 围栏 + 拍照，异常再人工审 |
| 防作弊要求高 | 人脸活体，再叠加位置或设备校验（多因子） |
| 居家 / 弹性办公 | 一般不靠定位，改成工时填报或审批，避免全天追踪位置 |

选型时通常看四件事：

1. 地点是否可信
2. 能不能防代打
3. 员工是否愿意用
4. 人脸和定位是否合规（告知同意、最小化采集、限定保存期限）
